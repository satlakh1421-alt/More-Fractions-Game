# 🍰 More Fractions Game
An interactive, visual educational math game designed to strengthen understanding of fractions, comparisons, and equivalent parts through intuitive problem-solving.

## 🚀 Features
- **Visual Fraction Challenges:** Compare, add, and identify fractions using intuitive visual models and bars.
- **Multiple Game Modes:** Practice comparing fractions (greater than / less than), finding equivalents, or matching numerical values to visuals.
- **Adaptive Difficulty:** Progress from simple common denominators to mixed numbers and unlike fractions.
- **Instant Feedback:** Immediate checks to reinforce mathematical understanding on each question.
- **Clean & Lightweight:** Fast loading and responsive on modern web browsers.

## 🎮 How to Play
1. Start a new game session.
2. Examine the fraction problem or visual representation displayed on the screen.
3. Select the correct option, drag matching fraction tiles, or determine which fraction is larger/smaller.
4. Submit your answer to score points and advance through the levels!

## 🛠️ Getting Started & Installation
To run or test this project locally:

1. **Clone the repository:**
   git clone https://github.com/satlakh1421-alt/More-Fractions-Game.git

2. **Navigate to the project directory:**
cd More-Fractions-Game

3. **Run the game:**
Open index.html directly in your browser, or launch it with a local server (such as VS Code Live Server or python3 -m http.server 8000).
